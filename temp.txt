7. 분석 결과 상세 화면

7.1. 종합 판단 조회 (요약 + 핵심 리스크(POINT) + 권고사항(ACTION ITEM))
7.1.1. [펼치기] 클릭 시 > 요약·POINT·ACTION ITEM 상세 표시
7.1.2. [접기] 클릭 시 > 요약 영역만 축소 표시

7.2. 논점(그룹)별 판단 목록 조회
7.2.1. 특정 논점 클릭 시 > 7.3 화면(논점별 상세)으로 이동

7.3. 논점별 상세 조회
7.3.1. 진입 시 > 근거 서술, 반대 측 논리 표시
7.3.2. 설비 과제인 경우 > 심의 등급 함께 표시
7.3.3. [법률 근거 보기] 클릭 시 > 관련 법률 조항 상세 표시

7.4. 결과 리포트 생성/내보내기
7.4.1. [리포트 생성] 클릭 시 > 텍스트 리포트 생성
